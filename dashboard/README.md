# Sales Data Pipeline Dashboard

## Overview
Power BI dashboard connected to SQLite data warehouse
showing real-time sales analytics.

## KPIs Tracked
- Total Revenue
- Total Orders
- Average Order Value
- Top Category
- Revenue by Status

## How to Connect
1. Open Power BI Desktop
2. Click Get Data
3. Select SQLite
4. Navigate to data/sales_warehouse.db
5. Load fact_sales table
